Stepped line plot of up to four series over time, with a legend and the last value labelled at each line end.

- Edit `x` (the time labels) and `series` (name and values) in `data-chart`.
- Put the series the slide is about first: it takes oxblood.
- Lines are stepped: each value holds across its own tick. Use it for one value per period, such as monthly totals. Do not use it to suggest a smooth trend between points.
- Use one y-axis only. Two measures on different scales need two charts.
- Write the source line under the chart.
