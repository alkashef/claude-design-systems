# presentation-pixelated

A pixelated design system for 16:9 technical presentations, built as one self-contained HTML file.

## Status

In progress. The Claude Design System artifact `presentation-pixelated` starts as a copy of `presentation-editorial` and is being restyled. This folder holds the system's files once the restyle is mirrored here. Until then, use `presentation-editorial/` for the structure: tokens, slide layouts, guidelines and a single-file template.

## What this folder will hold

- `README.md`: this file, then the brand book for the system (content fundamentals, visual foundations, iconography).
- `tokens.json`: colors, type, spacing and radius.
- `components/`: one folder per slide layout, with guidelines and a live preview, plus `bundle.css`.
- `template/presentation-template.html`: the single-file deck template.
