# claude-design-systems

Design systems built with Claude. Each folder is one system, mirrored from its Claude Design System artifact.

| Folder | What it holds |
| --- | --- |
| `presentation-template/` | Editable HTML template for 16:9 presentations: tokens, five slide layouts, and a self-contained template file. |

Open `presentation-template/template/presentation-template.html` in a browser. Press `E` to edit, `F` for full screen.
