# claude-design-systems

Design systems built with Claude. Each folder is one system, mirrored from its Claude Design System artifact.

| Folder | What it holds |
| --- | --- |
| `presentation-template/` | Editorial template for 16:9 presentations: tokens, 13 slide layouts (including bar, pie, line, scatter and table), guidelines, and a single-file HTML template. |

Open `presentation-template/template/presentation-template.html` in a browser. Press `E` to edit, `F` for full screen, `T` for the contents panel.

The repo copy of the template loads Instrument Serif and Instrument Sans from Google Fonts. The copy in the Claude artifact embeds the font files, so it also works offline.
